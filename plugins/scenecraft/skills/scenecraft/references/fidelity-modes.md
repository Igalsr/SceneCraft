# Fidelity modes

Use `hero-view` for one controlling reference. Optimize the locked camera, silhouette, visible proportions, facade rhythm, material blocks, and lighting appearance. Mark unseen structure as unconstrained.

`multi-view` is planned but blocked by the current runtime. When implemented, use it only when two or more images show meaningfully different sides and solve shared geometry and cameras together.

`metric` is planned but blocked by the current runtime. When implemented, use it only when dimensions, plans, known object sizes, camera calibration, or equivalent scale evidence exists. Image similarity alone does not establish real-world dimensions.

Ask for more images only when missing evidence prevents the requested fidelity, not merely because additional images would be convenient. Useful additions are orthogonal elevations, a rear view, an uncluttered facade, plans, or one known measurement.
